# Brewer

- Brewer is a static coffee recipe calculator intended for GitHub Pages under the `/brewer/` project path. Keep asset and data paths relative.
- Calculations and personal recipes run in the browser; local recipes stay in browser storage. Do not require a backend or user account without an explicit project decision.
- Recipe steps are free text and retain their original quantities; scaled ingredient quantities are authoritative.
- Keep machine-specific and working state in `.local/`, which is excluded from Git.
- Validate recipe data and exercise the calculator, personal recipes, sharing, and timer when changing those features.
